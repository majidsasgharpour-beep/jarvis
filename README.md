# دستیار جارویس — نسخه‌ی وب برای آیفون

یک دستیار صوتی فارسی‌زبان (Gemini Live) با ظاهر APEX (اورب طلایی، هسته‌ی ذرات، گراف عامل‌ها و بک‌گراند شیدر) که داخل Safari اجرا می‌شه؛ بدون نصب هیچ برنامه‌ای.

## امکانات
- گفتگوی صوتی زنده (هر زبانی، پیش‌فرض فارسی) + تایپ کردن؛ اورب APEX با صدا زنده می‌شه: گوش دادن، فکر کردن و حرف زدن هرکدوم حالت خودشون رو دارن (روی اورب بزن!)
- جستجوی وب (در حالت صوتی و متنی)
- **تولید تصویر**: «یه تصویر از غروب توی کویر بساز» (دکمه‌ی ذخیره/اشتراک زیر تصویر)
- **دیدن صفحه‌ی گوشی** از طریق اسکرین‌شات (پایین توضیح دادم) + دیدن با دوربین + فرستادن عکس
- **باز کردن برنامه‌ها**: «واتساپ رو باز کن»، «توی یوتیوب دنبال … بگرد»، یا دکمه‌ی 🚀 برنامه‌ها
- **شورتکات / سیری**: اجرای هر شورتکاتی که خودت ساختی (پایین)
- تماس، پیامک، ایمیل، مسیریابی در نقشه (با تأیید خودت)
- کارها (To-do) و یادداشت‌ها، ماشین‌حساب، تبدیل ارز، موقعیت و آب‌وهوای همین‌جا
- حافظه‌ی دائمی، تایمر، ساعت و تاریخ
- تغییر رنگ رابط، رنگ مو، اسم دستیار و صدا (۵ صدا)

## راه‌اندازی (یک‌بار)
1. کلید رایگان بگیر: https://aistudio.google.com/apikey
2. برای **نسخه‌ی عمومیِ کامل** پروژه را روی **Cloudflare Pages** منتشر کن؛ این پروژه از Pages Functions برای API استفاده می‌کند.
3. در Cloudflare داخل Workers & Pages → پروژه → Settings → Variables and Secrets یک **Secret** با نام `GEMINI_API_KEY` بساز و کلید Gemini را داخل آن قرار بده. کلید را داخل GitHub commit نکن.
4. بعد از Deploy، لینک Cloudflare Pages را در **Safari** آیفون باز کن ← Share ← **Add to Home Screen**.
5. برنامه را باز کن؛ برای نسخه‌ی عمومی لازم نیست کلید را داخل ⚙️ وارد کنی. آدرس API به‌صورت پیش‌فرض `/api/gemini` است. بعد دکمه‌ی میکروفون یا «🎨 تصویر بساز» را بزن.

### استقرار با Cloudflare Pages
- Repository را به Cloudflare Pages وصل کن و ریشه‌ی repository را به‌عنوان پوشه‌ی پروژه انتخاب کن. چون آواتار React/TSX است، پروژه باید بیلد شود: Build Command را `npm run build` و Build output directory را `dist` بگذار (فایل‌های ثابت مثل `apex-orb.js`، `sw.js`، `manifest.webmanifest` و آیکون‌ها داخل `public/` هستند و بدون تغییر به `dist` کپی می‌شوند). برای Workers، `wrangler.jsonc` همین بیلد را خودش اجرا می‌کند و از `dist` سرو می‌کند.
- فایل `functions/api/gemini.js` API را اجرا می‌کند و مسیر آن `/api/gemini` است.
- اگر `GEMINI_API_KEY` تنظیم نشده باشد، متن، Live و تولید تصویر خطای اتصال می‌دهند.
- برای امنیت بیشتر می‌توانی `JARVIS_ALLOWED_ORIGIN` را هم به‌عنوان متغیر/Secret روی آدرس دقیق سایتت بگذاری.
- Cloudflare می‌تواند فایل‌های استاتیک و Worker/Function را در یک پروژه سرو کند.
- منطق مشترک API در `api-core.js` است و هم `worker.js` و هم `functions/api/gemini.js` از آن استفاده می‌کنند (این فایل در `.assetsignore` است و به‌صورت استاتیک سرو نمی‌شود).
- پروکسی فقط نام مدل‌های `gemini-*` را قبول می‌کند. برای قفل کردن روی چند مدل مشخص، متغیر `JARVIS_ALLOWED_MODELS` را با لیست جداشده با کاما بگذار (مثلاً `gemini-3.8-flash,gemini-3.1-flash-image`).
- وقتی `JARVIS_ALLOWED_ORIGIN` ست باشد، درخواست‌های بدون هدر Origin هم رد می‌شوند. این پروکسی محدودیت تعداد درخواست ندارد؛ در Cloudflare یک Rate Limiting rule برای `/api/gemini` بساز تا کلیدت سوءاستفاده نشود.
- **GitHub Pages سرور ندارد**: روی `*.github.io` مسیر `/api/gemini` وجود ندارد، پس آنجا فیلد «آدرس API سرور» خالی می‌ماند و باید کلید شخصی را در ⚙️ وارد کنی (یا آدرس کامل Worker/Pages خودت را در همان فیلد بنویسی).
- بعد از Deploy، اگر Safari نسخه‌ی قدیمی را نشان داد، صفحه را یک‌بار Refresh کن یا PWA را کامل ببند و دوباره باز کن. نسخه‌ی service worker در این release bump شده است.

> اگر نسخه‌ی قبلی رو آپلود کرده بودی: فایل‌های `orb3d.js` و `char.js` دیگه لازم نیستن. فایل‌های `apex-orb.js`، `apex-world.js` و `apex-world.css` رو حتماً کنار `index.html` بگذار. برای اینکه گوشی نسخه‌ی جدید رو بگیره، برنامه رو یک بار کامل ببند و دوباره باز کن.

## دیدن صفحه‌ی گوشی (واقعیت‌ها)
سافاری در آیفون اجازه‌ی ضبط صفحه به وب‌سایت‌ها نمی‌ده، پس دیدن زنده‌ی صفحه ممکن نیست. راه عملی اسکرین‌شاته:
- دستی: اسکرین‌شات بگیر ← برگرد به جارویس ← دکمه‌ی 🖥 صفحه ← «چسباندن» یا «انتخاب از گالری» ← سؤالت رو بپرس.
- نیمه‌خودکار با شورتکات: یه شورتکات بساز با این اکشن‌ها: **Take Screenshot** ← **Copy to Clipboard** ← **Open URLs** با آدرس `https://آدرس-سایتت/#screen`. بعد از Settings ← Accessibility ← Touch ← **Back Tap** ← Double Tap همین شورتکات رو انتخاب کن. حالا هر جا باشی دو بار به پشت گوشی بزن، جارویس باز می‌شه و فقط «چسباندن» رو می‌زنی. (لینک در سافاری باز می‌شه، نه در برنامه‌ی نصب‌شده.)
- روی دسکتاپ و اندروید، دکمه‌ی ضبط زنده‌ی صفحه هم هست.

## باز کردن برنامه‌ها و فرمان به سیری
- جارویس از لینک‌های رسمی برنامه‌ها استفاده می‌کنه (واتساپ، تلگرام، اینستاگرام، یوتیوب، نقشه، اسپاتیفای و …). آیفون هر بار از تو تأیید می‌گیره؛ این محدودیت خود iOS هست. اگر خودکار باز نشد، دکمه‌ی «باز کردن …» که توی چت میاد رو بزن.
- مرورگر نمی‌تونه مستقیم با سیری حرف بزنه. پل ارتباطی **Shortcuts** هست و جارویس می‌تونه هر شورتکات رو اجرا کنه (`run_shortcut`). برای برنامه‌هایی که لینک ندارن، یه شورتکات با اسم **OpenApp** (یا هر اسمی که در تنظیمات پیشرفته گذاشتی) بساز:
  1. اکشن **Dictionary** با کلیدهایی مثل `بله` → `bale://` و `ایتا` → `eitaa://` و … (هر برنامه و آدرس‌اش)
  2. اکشن **Get Dictionary Value** (Value for: **Shortcut Input**)
  3. اکشن **Open URLs**
  اگر آدرس یک برنامه رو نمی‌دونی، اسم URL scheme اش رو از سایت‌های مرجع پیدا کن.
- برعکسش هم ممکنه: شورتکاتی با اکشن **Open URLs** به آدرس جارویس بساز و بهش بگو «جارویس» تا با «هی سیری، جارویس» جارویس رو باز کنی.

## نکته‌ها
- Gemini API در ایران مستقیم باز نمی‌شه؛ گوشی باید فیلترشکن (VPN) روشن داشته باشه.
- با بلندگوی گوشی ممکنه صدای خودش رو بشنوه؛ به همین خاطر وقتی داره حرف می‌زنه میکروفون بسته‌ست. با هدفون می‌تونی «اجازه‌ی وسط‌پریدن» رو در تنظیمات روشن کنی.
- وقتی از جارویس بیرون می‌ری (مثلاً برنامه‌ای رو باز می‌کنه)، آیفون گفتگوی صوتی رو متوقف می‌کنه؛ برگردی دوباره میکروفون رو بزن.
- تولید تصویر از `gemini-3.1-flash-image` و API جدید Interactions استفاده می‌کند؛ این مدل برای تولید و ویرایش تصویر طراحی شده و خروجی 1K/2K را پشتیبانی می‌کند. ممکن است دسترسی یا سهمیه‌ی تصویر برای کلید/حساب شما محدود باشد. اگر خطا داد: ⚙️ ← پیشرفته ← نام مدل تصویر.
- در **نسخه‌ی عمومی** کلید Gemini فقط روی Cloudflare به‌عنوان Secret می‌ماند و مرورگر آن را دریافت نمی‌کند. حالت «کلید Gemini API (حالت شخصی)» هنوز برای استفاده‌ی مستقیم/آزمایشی وجود دارد؛ برای سایت عمومی از آن استفاده نکن.
- اگر مدل Live عوض شد: ⚙️ ← پیشرفته ← نام مدل.
