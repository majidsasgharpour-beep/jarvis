# دستیار جارویس — نسخه‌ی وب برای آیفون

یک دستیار صوتی فارسی‌زبان (Gemini Live) که داخل Safari اجرا می‌شه؛ بدون نصب هیچ برنامه‌ای.

## امکانات
- گفتگوی صوتی زنده (هر زبانی، پیش‌فرض فارسی) + تایپ کردن
- جستجوی وب (Google Search داخل Gemini)
- حافظه‌ی دائمی (چیزهایی که درباره‌ات می‌گی رو یادش می‌مونه؛ از دکمه‌ی 🧠 می‌بینی و حذف می‌کنی)
- آب‌وهوا، ساعت و تاریخ، تایمر (فقط وقتی برنامه باز باشه زنگ می‌زنه)
- دیدن با دوربین (بگو «به اطرافم نگاه کن») و ارسال عکس از دکمه‌ی 📷
- تغییر رنگ رابط، اسم دستیار، صدا (۵ صدا)
- حالت متنی خودکار اگر Live در دسترس نبود

## راه‌اندازی (یک‌بار)
1. کلید رایگان بگیر: https://aistudio.google.com/apikey
2. پوشه را روی یک هاستینگ **HTTPS** بگذار (میکروفون فقط روی HTTPS کار می‌کنه):
   - ساده‌ترین: https://app.netlify.com/drop ← کل پوشه را بکش و رها کن، لینک می‌گیری.
   - یا GitHub Pages / Cloudflare Pages / Vercel.
3. لینک را در **Safari** آیفون باز کن ← Share ← **Add to Home Screen**.
4. برنامه را باز کن ← ⚙️ ← کلید API را بگذار ← ذخیره ← دکمه‌ی میکروفون.

## نکته‌ها
- Gemini API در ایران مستقیم باز نمی‌شه؛ گوشی باید فیلترشکن (VPN) روشن داشته باشه.
- با بلندگوی گوشی ممکنه صدای خودش رو بشنوه؛ به همین خاطر وقتی داره حرف می‌زنه میکروفون بسته‌ست. با هدفون می‌تونی «اجازه‌ی وسط‌پریدن» رو در تنظیمات روشن کنی.
- کلید API فقط داخل مرورگر خودت ذخیره می‌شه و مستقیم به Google می‌ره.
- اگر مدل Live عوض شد: ⚙️ ← پیشرفته ← نام مدل.
- کلید یا لینک را با کسی به اشتراک نگذار؛ هر کس لینک را باز کند باید کلید خودش را بگذارد.
