# پیشران | سایت کلاس‌های هوش مصنوعی

یک سایت استاتیک فارسی (راست‌به‌چپ) که اول نشان می‌دهد مدرک به‌تنهایی کافی نیست، بعد دستاوردهای ثبت‌شده‌ی هوش مصنوعی را روی یک خط زمانی می‌آورد و در پایان به ثبت‌نام کلاس‌ها می‌رسد.

## فایل‌ها

- `index.html`: محتوا و متن‌ها
- `style.css`: ظاهر
- `script.js`: فرم ثبت‌نام و تنظیمات

## چیزهایی که باید خودت تنظیم کنی

- آی‌دی تلگرام برای دریافت ثبت‌نام‌ها: بالای `script.js`، مقدار `CONFIG.telegram` (بدون @). تا پر نشود، فرم پیام «ثبت‌نام هنوز فعال نشده» نشان می‌دهد.
- نام برند «پیشران»: در `index.html` و `style.css` با جست‌وجو عوض می‌شود.
- سرفصل‌های کلاس‌ها: بخش `.modules` در `index.html`.

## اجرای محلی

```
npx serve .
```

## استقرار (Cloudflare)

```
npx wrangler deploy
```
